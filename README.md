# 🎬 Movie Ticket Booking System (C Programming)

A **console-based Movie Ticket Booking System** developed using **C programming**.
This project simulates an online cinema ticket booking portal where users can log in, view movies, book tickets, select show times and dimensions, make payments, and store booking data in files.

---

## 📌 Features

* 🔐 **User Login System**

  * Default password authentication
* 🎥 **Currently Showing Movies**
* 🎞 **Upcoming Movie Premier List**
* 🎟 **Ticket Booking System**

  * Movie selection
  * Dimension selection (IMAX / 3D / 2D)
  * Show time selection
  * Ticket quantity
* 💳 **Payment Simulation**

  * Calculates total payable amount
* 🧾 **Customer Information Collection**
* 💾 **File Handling**

  * Stores booking details in `tick_info.txt`
  * Stores movie requests in `request_info.txt`
* 📩 **Movie Request System**

  * Request movies for re-screen or premiere
